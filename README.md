## как пользоваться

Начинай с тематической карты, переходи к самостоятельным понятиям и связанным источникам. Учебные конспекты сохраняют порядок изложения источника; упражнения и решения — отдельный материал для практики.

Роли разделены физически: обзоры — `notes/maps/`, понятия — `notes/concepts/` с тематическими подпапками, материалы источников — `notes/sources/`, учебная практика — `notes/practice/` и существующая `notes/_homework/`. Математика размещается в `notes/concepts/math/`. Оставшиеся в старых предметных папках смешанные заметки требуют отдельного ревью; перенос не означает проверки содержания.
