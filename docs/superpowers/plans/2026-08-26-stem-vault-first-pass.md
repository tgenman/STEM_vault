# План первичного документирования STEM-хранилища

> **Для агентов-исполнителей:** ОБЯЗАТЕЛЬНЫЙ ДОПОЛНИТЕЛЬНЫЙ НАВЫК: используйте `superpowers:subagent-driven-development` или `superpowers:executing-plans` только для порученных вам шагов по документированию. Исследование репозитория выполняется только для чтения.

**Цель:** восстановить текущие процессы работы с базой знаний и Anki, затем оставить краткий маршрутизатор для агентов и минимальный набор стабильных и датированных справочных документов, необходимый для дальнейшей работы.

**Архитектура:** существующие заметки, шаблоны, конфигурация, история Git и блоки Anki остаются первичными свидетельствами. `AGENTS.md` будет содержать только постоянно необходимые правила и маршрутизацию задач; стабильное руководство по репозиторию будет содержать подробную карту и соглашения; датированный аудит отделит подверженные изменениям показатели, противоречия, возможные содержательные ошибки и незавершённые области.

**Технологии:** Obsidian Markdown, YAML frontmatter, wikilinks, LaTeX, Obsidian_to_Anki, проверка Git только для чтения.

**Техническое задание:** предоставленный пользователем промпт первичного аудита в задаче Codex от 2026-08-26.

**Статус:** выполнено и проверено 2026-08-26.

## Общие ограничения

- Сохранять все существовавшие до начала работы изменённые и неотслеживаемые файлы; не редактировать существующие учебные заметки, карточки, шаблоны, скрипты и сгенерированные артефакты.
- Не перемещать, не переименовывать, не удалять и не коммитить файлы, не выполнять reset или checkout, не генерировать карточки Anki и не запускать команды, записывающие данные в хранилище, кроме создания или редактирования согласованных файлов документации.
- Считать текущее содержимое репозитория первичным свидетельством; помечать исторические документы и выведенные соглашения уровнем уверенности.
- Отделять стабильные правила от датированного снимка репозитория.
- Фиксировать возможные математические ошибки для последующей проверки; не исправлять их в рамках этого прохода.
- Сохранять `AGENTS.md` кратким и направлять к подробным веткам через ссылки.
