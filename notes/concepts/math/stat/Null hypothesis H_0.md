> [!tip] null hypothesis $H_0$
> The hypothesis against which a statistical test evaluates evidence.

It can specify one parameter value or a set, for example $H_0:\mu=\mu_0$ or $H_0:\mu\le\mu_0$. It need not mean “no effect” in every test.

Source: [NIST: statistical tests](https://www.itl.nist.gov/div898/handbook/prc/section1/prc13.htm).
