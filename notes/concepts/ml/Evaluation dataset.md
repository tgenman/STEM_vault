> [!tip] evaluation dataset / eval-set
> Набор примеров для оценки системы, покрывающий реальные запросы и сложные случаи и пополняемый по мере обнаружения ошибок.

Краткий пересказ раздела 5.1, а не дословное определение: отдельного определения eval-set в ноутбуке нет.

## состав и покрытие

Краткий пересказ разделов 5.1 и 8:

- В практическом задании пример содержит вопрос, контекст и эталонный ответ; это состав конкретного eval-сета, а не обязательная схема всех оценочных наборов.
- [[Golden set]] содержит вручную размеченные или проверенные экспертом эталоны.
- [[Edge cases]] включают неоднозначные вопросы, отсутствие ответа в контексте, multi-hop и границу домена.
- Набор должен покрывать реальное распределение запросов, а не только простые случаи.
- Реальные ошибки из production добавляются в набор для последующих проверок.

## синтетические вопросы

Дословно из раздела 5.1:

> генерируются LLM на основе базы знаний/документов (полезно для быстрого расширения покрытия, но требует контроля качества — синтетика может быть проще реальных запросов пользователей).

Применение: offline-оценка и регрессионные проверки в [[LLM evaluation]].
