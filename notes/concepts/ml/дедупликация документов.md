> [!tip] дедупликация документов
> Обнаружение и удаление повторяющихся документов.

Различают точные дубликаты и near-duplicates — почти совпадающие документы. Ноутбук рассматривает поиск последних связкой **MinHash LSH**: [[Shingling]] → [[MinHash]] → [[Locality Sensitive Hashing|LSH]].

В учебном коде из найденной группы оставляют один документ. Перед поиском выполняется очистка текста.

Краткое описание по материалам ноутбука «Воркшоп: Препроцессинг данных для RAG» (`4_RAG_Preprocessing_Workshop_Updated.ipynb`), раздел 2; не дословная цитата.
