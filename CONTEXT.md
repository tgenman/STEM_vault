# контекст перебора STEM

Этот контекст задаёт язык конечного последовательного просмотра `STEM_vault`. Перебор отделяет факт покрытия корпуса от исправления всех найденных проблем.

## язык

**Перебор STEM**:
Ограниченная кампания, в которой каждый объект согласованного охвата просмотрен и получил явное решение. Перебор не требует исправить все найденные проблемы.
_Избегать_: генеральная чистка, миграция STEM

**Просмотрено**:
Объект изучен достаточно, чтобы принять решение о его текущей судьбе. Это не синоним «исправлено», «идеально» или «завершено».
_Избегать_: готово, вычищено

**Служебный слой**:
Инструкции, Cursor rules, templates, отчёты и другие материалы, которые управляют работой с корпусом, но сами не являются человеческими знаниями STEM.
_Избегать_: мета-мусор, технические заметки

**Человеческий корпус**:
Заметки и библиографические материалы, содержащие знания, конспекты, задачи, источники или авторские заготовки Дмитрия.
_Избегать_: контентные файлы

**Пакет перебора**:
Небольшая осмысленная группа связанных объектов, которую можно понять и обсудить за один цикл. Один пакет решений не обязан становиться одним пакетом изменений.
_Избегать_: чанк, батч файлов

**Решение**:
Зафиксированная судьба просмотренного объекта: оставить без изменений, принять изменение, отложить конкретный вопрос или явно исключить по роли.
_Избегать_: статус заметки

**Реестр покрытия**:
Компактная каноническая запись того, какие объекты уже просмотрены и какое решение принято. Он не хранит всю аргументацию и не заменяет очередь найденных проблем.
_Избегать_: большой аудит, чеклист качества

**Отчёт пакета**:
Подробное обоснование и свидетельства для сложного пакета. Создаётся только когда решения нельзя надёжно понять из реестра покрытия.
_Избегать_: обязательный отчёт на каждый пакет

**Очередь вопросов**:
Отдельный ограниченный список конкретных проблем, сознательно не исправленных во время перебора. Наличие открытого вопроса не отменяет факт просмотра объекта.
_Избегать_: общий технический долг, бесконечный backlog

**Временный артефакт перебора**:
Реестр, отчёт или другой рабочий документ, нужный только для проведения и проверки текущей кампании. Он удаляется исключительно по прямой команде Дмитрия после закрывающей сверки.
_Избегать_: постоянная документация vault
